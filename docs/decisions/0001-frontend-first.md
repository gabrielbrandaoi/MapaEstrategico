# ADR 0001 — Frontend-first
- Status: Proposto
- Contexto: validar UX, Excel, mapa e regras sem custo inicial de backend.
- Decisão: MVP Angular/TypeScript sem banco, com adaptadores externos.
- Benefícios: ciclo rápido e menor complexidade.
- Custos: dados voláteis, limites do navegador e dependência externa.
- Reavaliar para múltiplos usuários, histórico, auditoria, persistência ou escala.
